# Stress Project

This is an E2E stress test project for the precision_engine toolset.

## Overview

The project contains a complete TypeScript application structure including:

- **Models**: User and Product entities with full type safety
- **Services**: Authentication and database connection management
- **Utils**: Helper functions and validators
- **Config**: Application configuration with YAML support
- **Tests**: Comprehensive test suite with Vitest

## Installation

```bash
npm install
```

## Build

```bash
npm run build
```

## Test

```bash
npm test
```

## Type Check

```bash
npm run typecheck
```

## Architecture

### Models Layer
Contains domain entities and their business logic.

### Services Layer
Provides application services like authentication and data access.

### Utils Layer
Shared utilities and validation logic.

### Config Layer
Environment-specific configuration management.
