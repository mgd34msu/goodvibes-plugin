# Mini String Utils Library

Build a small string utility library with tests.

## Functions
- `slugify(input: string): string` — convert to URL-safe slug
- `truncate(input: string, maxLen: number, suffix?: string): string` — truncate with ellipsis
- `capitalize(input: string): string` — capitalize first letter of each word
- `countWords(input: string): number` — count words in string
- `reverse(input: string): string` — reverse string

## Files
- `delete-me/strings.ts` — implementation
- `delete-me/strings.test.ts` — vitest tests
